# Azure AWS CIDR overlap detection

This Python script demonstrates how to detect overlapping CIDR blocks between hypothetical Azure and AWS network plans. It uses the ipaddress module to check for conflicts, which is a critical step in multi-cloud migration planning.

## Language

`python`

## How to Run

Run this script using Python: python cidr_planner.py
